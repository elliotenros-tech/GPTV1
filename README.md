# Parkdale Athletics

A responsive athletics hub for Parkdale Collegiate Institute, with intramural schedules, tryouts, and recent scores. Includes a collapsible sidebar and sport filters.

## Run

Requires Node.js 18 or later. No package installation is required.

```sh
npm run dev
```

The server listens on port 3000, or the `PORT` environment variable. Run `npm test` for JavaScript syntax checks.

## Content

All schedules, teacher names, and scores are illustrative sample data, clearly labeled in the app. Update the arrays in `public/app.js` with verified school information before public use. This version has no backend or live school-data integration.

The orange and charcoal visual identity uses a custom typographic P mark. The supplied panther logo has not been embedded as an image asset. DM Sans loads from Google Fonts, with Arial as an offline fallback.
